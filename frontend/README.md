# Softlligence Manufacturing Cloud - Frontend

This is the main Next.js web application codebase for the Softlligence Multi-Tenant Manufacturing ERP platform.

For the comprehensive, recruiter-ready overview of the technology stack, system architecture, feature maps, and directory details, please refer to the **[Root Repository README.md](../README.md)**.

---

## 🛠️ Tech Stack Quick Summary
* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling:** Vanilla CSS & TailwindCSS
* **State Management:** React Context API & LocalStorage synchronization
* **Data Visualization:** High-performance responsive custom SVG charts

## ⚙️ Getting Started

### Installation
1. Install project dependencies:
   ```bash
   npm install
   ```
2. Start the local development server:
   ```bash
   npm run dev
   ```
3. Navigate to [http://localhost:3000](http://localhost:3000) to view the client.

### Building for Production
To build the static optimized application bundle:
```bash
npm run build
```
The build completes successfully with zero compile warnings or static check errors.
